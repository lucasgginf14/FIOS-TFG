# Usuarios de prueba

[Volver al README principal](../README.md)

El proyecto FIOS incluye varias cuentas ficticias para poder probar la aplicacion sin crear usuarios nuevos. No corresponden a personas reales.

La mayoria de cuentas indicadas en este documento utilizan la misma contrasena:

```text
Fios2026!
```

## Cuentas principales

| Cuenta | Contrasena | Rol | Funciones que permite probar |
| --- | --- | --- | --- |
| `admin@fios.com` | `Fios2026!` | `ADMIN` | Panel de administracion, gestion de usuarios, revision de espacios, eventos, reservas y resenas. |
| `lucas@fios.com` | `12345678a` | `USER` | Demo completa de Lucas: perfil con instrumento, busquedas, reservas propias y recibidas, mensajes, espacio gestionado `Boa`, banda `The Rapants`, reclutamiento, evento, entrada, favoritos y resenas. |
| `alba.moure@fios.com` | `Fios2026!` | `USER` | Gestion del espacio `Estudio Noroeste`, liderazgo de la banda `Bruma Norte`, actividad de bandas y eventos internos. |
| `nico.falcon@fios.com` | `Fios2026!` | `USER` | Gestion del espacio `Sala Porto Alto`, liderazgo de la banda `Latido Verde`, reservas recibidas y mensajes asociados. |
| `lucia.castro@fios.com` | `Fios2026!` | `USER` | Reservas, compra de entradas, participacion en banda y revision de actividad personal. |
| `irene.valverde@fios.com` | `Fios2026!` | `USER` | Liderazgo de la banda `Ria Electrica` y propuesta de eventos que quedan pendientes de aprobacion. |

## Que cuenta usar en cada caso

- Administracion: `admin@fios.com`.
- Gestion de espacios: `lucas@fios.com`, `alba.moure@fios.com` o `nico.falcon@fios.com`.
- Bandas: `lucas@fios.com`, `alba.moure@fios.com`, `nico.falcon@fios.com`, `lucia.castro@fios.com` o `irene.valverde@fios.com`.
- Reservas: `lucas@fios.com` o `lucia.castro@fios.com`.
- Mensajes: `lucas@fios.com`, `nico.falcon@fios.com` y `lucia.castro@fios.com`.
- Resenas: `lucia.castro@fios.com`.
- Eventos: `admin@fios.com` para administracion e `irene.valverde@fios.com` para proponer eventos vinculados a bandas.
